# Sakura Sushi

A professional-looking, beginner-friendly sushi restaurant website built for a first-year college project.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Go to Menu and test the cart/checkout flow.

## Main flow
Home → Menu → Add to Cart → Cart → Checkout → Order Confirmation

No real payment, email delivery, or backend database is connected. Orders are demo orders stored locally in the browser.
