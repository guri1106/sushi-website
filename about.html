Tradition Meets Innovation

Our Story

Inspired by the serene beauty of Kyoto cherry blossoms and the meticulous art of sushi craftsmanship.

Sakura Sushi began with an appreciation for authentic Japanese culinary principles: letting pristine, uncompromised ingredients speak for themselves through patience, knife mastery, and precise seasoning.

From hand-forming warm vinegared rice for each nigiri piece to simmering our ramen bone broths for twelve unhurried hours, we celebrate the philosophy of shokunin—the endless pursuit of culinary refinement.

🎓 Academic Project Disclosure

Sakura Sushi is a conceptual Japanese restaurant website developed as a first-year college web development project. It demonstrates modern responsive frontend design, client-side data management using Vanilla JavaScript & LocalStorage, and accessible UI/UX. This is not an operating commercial business.

Viva Presentation Guide

Technical Implementation Overview

This project is intentionally engineered using standard Web Standards (HTML5, CSS3, and Vanilla JavaScript ES6+) so that any first-year student can confidently explain the code to an external examiner during a practical viva examination:

1. Semantic HTML5 Architecture

Constructed using semantic tags (<header>, <nav>, <main>, <article>, <footer>) for clean code hierarchy and accessibility.

2. Pure CSS3 with Modern Layouts

Built using CSS Grid, Flexbox, custom CSS Variables for theming, and media queries for responsive mobile adaptation without external CSS frameworks.

3. Vanilla JavaScript State & DOM

Zero dependencies or frameworks. Items are rendered dynamically using array methods (filter(), map(), reduce()) and template literals.

4. LocalStorage Data Persistence

Preserves shopping cart items and the placed order ID across page refreshes and multi-page checkout flow using localStorage.setItem() and getItem().
